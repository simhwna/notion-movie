# IMDb 순위 갱신과 영화 판별

실행: `python scripts/refresh_top250_with_identity.py`

`refresh_top250.py`의 차트 수집, 한국어 제목 보강, 통신 함수를 재사용한다. GitHub의 예약·수동 작업은 이 실행 파일을 사용하도록 변경해야 한다. 기존 실행 파일을 그대로 호출하면 이전 판별 방식이 유지된다.

## 판별 순서

1. 노션의 IMDb ID가 있으면 ID로만 비교한다. 영문 대문자와 IMDb 영화 URL을 정규화하고 선행 0을 보존한다.
2. ID가 정상 형식이지만 현재 Top 250에 없으면 차트 밖 영화로 처리한다. 제목이 같더라도 다른 영화의 순위를 가져오지 않는다. 기존 순위는 비우고 평점은 같은 ID로 조회한다.
3. 입력된 ID가 잘못된 형식이면 해당 행의 순위·평점·ID를 모두 보존한다.
4. ID가 비어 있으면 제목과 한국어 별칭의 유일한 후보를 사용한다. 제목 후보가 겹치면 변경하지 않는다.
5. 제목으로 찾지 못하면 위키데이터 결과 전체에서 IMDb ID가 하나로 확정될 때만 사용한다. 여러 ID 중 차트에 있는 첫 항목을 선택하지 않는다.
6. 새로 판별한 ID는 비어 있는 텍스트 또는 URL 속성에만 쓴다. 기존 ID는 덮어쓰지 않는다.

불완전한 차트는 동기화 전에 거부한다. 판별 실패 시 기존 순위를 지우지 않으며, 평점 조회 실패 시 기존 평점을 보존한다. 자동 보고서는 판별 사유와 성공·실패 개수만 남긴다.

## 검사

```sh
python -m unittest discover -s scripts -p 'test_*.py' -v
```

검사는 시험용 데이터와 가짜 통신 응답만 사용한다. 노션 토큰이나 영화 API 키가 필요하지 않다. 기존 앱의 `data/top250.json` 주소와 JSON 필드는 유지한다. 안드로이드 소스와 실제 노션 기록은 이 변경 요청에서 수정하지 않는다.
